🖌️ WebPaint.js

轻量级网页绘画标注插件 · 零依赖 · 一行代码集成

🚀 快速体验

点击 「开始标注」 或右下角悬浮球进入标注模式，即可在整个页面上自由绘画。工具栏在右侧（手机上在底部），按住顶部的 ⠿ 手柄可拖到任意位置。试试新增的荧光笔 —— 半透明笔触，划重点神器。退出标注后，页面恢复正常交互，标注内容仍然保留。

📦 集成方式

只需引入一个 JS 文件，无任何依赖：

<script src="webpaint.js"></script>
<script>
  const wp = new WebPaint({
    color: '#e5484d',   // 默认颜色
    size: 4,            // 默认粗细
    toolbar: true,      // 使用内置工具栏
    autoEnable: false   // 是否立即进入标注模式
  });
  wp.enable();          // 进入标注模式
</script>

🔧 API 一览

方法说明
wp.enable() / disable() / toggle()进入 / 退出 / 切换标注模式（退出后画布穿透，不影响页面交互）
wp.setTool(tool)切换工具：pen / highlighter / arrow / rect / text / eraser
wp.setColor(color) / setSize(size)设置画笔颜色 / 粗细
wp.undo() / redo() / clear()撤销 / 重做 / 一键清空（支持 Ctrl+Z / Ctrl+Y）
wp.exportImage(opts)导出图片：{mode:'page'} 整页含标注，{mode:'layer'} 仅标注层
wp.getData() / loadData(data)获取 / 载入标注矢量数据（可持久化到服务器）
wp.on('change', fn)事件订阅：change / enable / disable / toolchange
wp.destroy()销毁插件，移除所有 DOM 与事件

📖 一段用来练手的文章

Canvas 是 HTML5 提供的位图绘制接口。WebPaint 在页面顶层铺设了一张覆盖整个文档的透明画布，所有绘制都以矢量对象的形式记录——这意味着窗口缩放、屏幕 DPR 变化时都可以无损重绘，撤销与重做也只是对对象列表的增删。

橡皮擦使用 destination-out 合成模式实现真正的"擦除"，而不是简单地涂白色；文字标注则会在点击处弹出一个所见即所得的输入框，回车即可落到画布上。试着在这段文字上划几笔重点线吧！
